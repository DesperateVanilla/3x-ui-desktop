Счётчики Qt Test включают init/cleanup; проверено 74 сценария без этих служебных шагов. В тестах форм используется offscreen-плагин; его предупреждение propagateSizeHints не влияет на проверки.

Визуально проверены обзор, серверы, подписки, настройки, пустое состояние и формы подключения/создания клиента. Обзор отдельно сохранён из обычного Windows-плагина готовой поставки. Примеры в screenshots демонстрационные.

Переносимая поставка запущена с PATH, содержащим только Windows/System32, и пустым QT_PLUGIN_PATH. Код выхода 0. Проверены загруженные модули: Qt Core/Gui/Widgets/Network/Sql, qwindows, qsqlite и qschannelbackend взяты из папки поставки. Рядом с EXE находятся app-local DLL Microsoft C++ runtime.

Проверка Windows DPAPI выполнялась в обычной учётной записи Windows: ограниченная среда Codex не даёт DPAPI доступ к ключам профиля. Защита не ослаблялась.

Подключения к реальным серверам пользователя и реальные изменяющие операции не проверялись: адреса и доступы не предоставлены. Совместимость API основана на исходниках 3x-ui 3.7.0 и моделируемых v2/v3 ответах; первую проверку конкретной версии следует выполнить на тестовом сервере.
